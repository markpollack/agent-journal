# OCSF self-describing package fixtures (non-production prototype)

Each directory is one labelled case for the Java OCSF reader, oracle and analysis views in
`io.github.markpollack.journal.tck.ocsf`: the native artifacts (`native/`), the independently frozen expected-source
manifest (`native/expected-sources.json`: artifact, profile, sha256, bytes, records and expected split cores, written
from the native files before any package is judged; the oracle's denominator, never the package's own `sources[]`),
the self-describing package layout `0.2.0-prototype` produced from them by the incremental Java writer (`package/`:
`run.json` + `events.jsonl`, children under `children/<spawn id>/`), the run spec the writer consumed (`spec.json`)
and, where present, hand-authored expected analysis answers (`expected-views.json`, written from the native records
and compared as a subset pattern).

Live-derived fixtures were sanitized by the steward's recorded script (paths, home directory, session and thread ids, record uuids,
user configuration names, memory and socket paths, account rate-limit numbers replaced; no key added or removed, no record dropped) and
re-frozen; `provenance.json` beside each states origin, capture command, CLI version, scenario, original and sanitized hashes and the
sanitization steps. Each core's execution records validate under the pinned toolkit; the committed summaries under `../validation/`
are tied to the event file hashes (`prototype/ocsf-acp/scripts/validate-fixtures.sh`).

Packages were produced by `journal-ocsf-writer` (`PublicFixtureRegenerationTest` with `-Docsf.regenerate=true`: byte
replay in 1 KiB chunks, fixed clock; the cancelled live recordings replayed to their end and interrupted with the live reason) against OCSF 1.9.0 `856d462b…` with extension `agentic_cli` 0.9.0-prototype (uid
901, provisional, compiled schema sha256 `9b77697bdc5b3f5433e3d064d25e4488c230634311abe634faf2f34745f6eb56`; the
current pin is in `prototype/ocsf-acp/toolchain.lock.json`). Every core validated with ocsf-toolkit v0.9.0 (0 errors;
`suspicious_other` enum-sibling warnings on `tool_kind` "other", a toolkit heuristic). The oracle and the reader never
call the writer.

Fixtures are not regenerated by the build. Regenerate them deliberately when the extension, the contracts or the
layout change (`./mvnw -pl journal-ocsf-writer test -Dtest=PublicFixtureRegenerationTest -Docsf.regenerate=true`),
and update this note.
