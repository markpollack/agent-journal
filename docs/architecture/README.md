# Architecture artifacts

This directory contains generated component views and recorded mapping examples.
Regenerate them from the repository root:

```bash
scripts/architecture-docs.sh
```

The script also supports `--appmap` to record the selected scenario and `--docx` to export
these technical pages and the tool-call story.

For project guides and API documentation, see [lab.pollack.ai](https://lab.pollack.ai/projects/agent-journal).
